# Anime / cel animation — asset prompts

[← all styles and rules](README.md)

- **Style prompt:** Japanese anime cel-shaded illustration, crisp dark line art, flat cel shading with one shadow tone, bright saturated colours, expressive large eyes, dynamic clean shapes
- **Palette:** bright pinks, sky blues, sunny yellows, teal, with dark purple-brown line art
- **Avoid:** painterly blending, photorealism, muddy colours, copying any existing anime character
- **Negative prompt (use with every prompt below):** text, letters, watermark, signature, logo, frame, border, multiple subjects, cropped, cut off, blurry, photo, photorealistic, 3d render, extra limbs, deformed hands, painterly blending, photorealism, muddy colours, copying any existing anime character
